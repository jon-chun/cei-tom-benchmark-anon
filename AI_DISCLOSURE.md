# AI Tools Disclosure

Per CogSci 2026 requirements, this document discloses the use of AI tools in this research.

## AI Tools Used

### 1. Large Language Models Under Evaluation

The following models were evaluated as **research subjects** (not authorship tools):

- GPT-5-mini (OpenAI)
- Claude Haiku 4.5 (Anthropic)
- Grok-4.1-fast (xAI)
- Gemini-3-flash-preview (Google)
- Qwen3-235B (Alibaba)
- Mistral-Small-24B (Mistral)
- DeepSeek-V3 (DeepSeek)
- Llama-3.1-8B (Meta)
- Gemma-3n-E4B (Google)
- Kimi-K2 (Moonshot)
- Minimax-M2P1 (Minimax)

### 2. Code Development Assistance

AI coding assistants were used for:
- Code refactoring and documentation
- Debugging and error resolution
- Statistical analysis verification

**Responsibility Statement**: All code was reviewed, tested, and validated by the authors. The authors take full responsibility for the accuracy, integrity, and originality of all content.

### 3. Manuscript Preparation

AI tools were used for:
- Grammar and style editing
- Literature synthesis (with manual verification)
- LaTeX formatting assistance

**Note**: AI tools were NOT used for:
- Generating research hypotheses
- Interpreting results or drawing conclusions
- Writing the core scientific arguments

## Compliance

This disclosure complies with the Cognitive Science Society's AI tools policy for CogSci 2026 submissions.
